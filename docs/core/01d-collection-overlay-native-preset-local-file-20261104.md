## 01D new source code: Overlay availability

`src/lib/ddv/core/items/local-item-overlay-read-contract.mjs` accepts the already loaded **reference index** and a reference to 01A's session bridge. This pure adapter **does not open/decode/save a P1G**, hash the reference shard bytes, query raw Player profile, issue a Worker cursor, or mint trusted Session identity; source index integrity must be established by the existing SHA-verifying `loadCollectionRuntime`.

It checks exact normalized target (Switch v1.25.0 Catalog versus 01A Worker v1.25.3). It outputs either `NO_ACTIVE_LOCAL_SAVE`, `CATALOG_AND_LOCAL_SAVE_BUILD_MISMATCH`, `ITEM_TYPED_READ_NOT_AVAILABLE_ON_WORKER`, or a strict blocked state. All paths return `owned/discovered/missing=UNKNOWN`, `quantity=null`, `entryDenominator/uniqueDenominator/progressRatio=null`, `canShowPersonalState=false`, `canShowPercentage=false`, `canWriteSave=false`. No caller `nativeVerified=true` parameter can turn on status. Synthetic bridge objects themselves are not authorization. Do not wire this as an active personal Save overlay until 01A issues an item-specific bounded read API with Core-owned capability.

## Native DDV Preset local-file operation: additional safety

Main already contains `src/lib/presets/native-preset-runtime.js`, `NativePresetManager.svelte`, and a schema624 `wand.in-game-preset-backup@1`/library local JSON backup + on-demand download. It separates **physical index** from active ordinal (20 active slots max); a deleted tombstone is `StateFlags & 0x10`, not arbitrary `Deleted` metadata. Full Game-native data in backup includes `World.DecorationPresets[*].GridCollection` with root Grid0/Objects/NextIDs and optional SubGrids, `PresetName`, `ThumbnailItems`, `ShareInfo`, `StateFlags`, opaque forward fields. Old saved backup schema624 records physicalIndex and active ordinal but **has no cryptographically authenticated original Build/BID**, even if file contains later user-authored claims.

New `src/lib/presets/native-local-file-import-contract.mjs` is an **offline PC JSON import reviewer**, not a game preset restore: accepts one legacy backup or a library up to 100 backups and 32MiB, strict UTF8/JSON, structural profile schema624 and exact known fields, ID uniqueness, bool/deleted/slot consistency, unknown field clone preservation, reserved prototype-name rejection, informational file SHA256. Malformed root Grid, deleted tombstone and non-null old ShareInfo can be **quarantined for local preservation only** (never silently converted to a restorable active preset). `sourceBuildAttested=false`, `sourceGameVersion/BID=null`, all game install/writer/public/Community permissions false. The review API itself does not write any browser storage. The existing **NativePresetManager.svelte** user-selected JSON import path is now wired to the reviewer: it checks size before read, accepts one local backup OR a local library, validates every backup and deduplicates without silently truncating beyond the 100-entry quota, and displays its localized structural-warning message for quarantined rows. The existing *optional* browser-local library and per-entry PC-file export remain; no mandatory cloud or account persistence. Restore/push buttons stay disabled. This product UI delta is Owner SOURCE/SYNTHETIC only until independent browser acceptance; existing on-demand PC backups remain separate from Community Presets.
