## Implemented offline analysis contract
Source: `scripts/asset-research/steam-switch-10pair-offline.py`. Input: `docs/core/01d-steam-switch-10pair-source-ledger-20261105.json` is a transparent **INCOMPLETE example**, not a verified 10-pair fixture. Populate a private-local copy with exactly 10 distinct ItemIDs, both original decoded PNG filenames and independently measured SHA256, source item-definition SHA and exact icon GUID references from both platforms, full version, external semantic match evidence, then run locally:
```bash
python3 scripts/asset-research/steam-switch-10pair-offline.py \
 --manifest /private/10pair_verified_sources.json \
 --source-root /private/original_pngs \
 --report /private/10pair_quality_measurements.json
```
Requires Pillow/PIL+libwebp installed locally. No network APIs, uploading, direct Wand UI or public manifest. Explicit refusal of duplicate IDs, non-10 slots, cross-Version, noncanonical SHA/PNG, absent/corrupt input, path escape/symlink, oversized originals. For each measured pair: native original dimensions, original PNG SHA256 + decoded RGBA SHA, alpha coverage and alpha bounds, 160×160 LANCZOS normalized geometry, **WebP `lossless=True, exact=True, method=4`**, decoded pixel-perfect RGBA verification and exact codec byte size+SHA per platform, normalized RGBA exact-match/MSE/PSNR, normalized alpha equality and edge-energy differences. 320px optional only when BOTH genuine native source width and height ≥320px. Edge energy/PSNR are **not** a proof of superior visual detail. A source PNG SHA alone does not prove native item identity without original game definition/Addressables mapping.
 
Source contract is research only and `productMigrationAuthority:false`; individual/aggregate photo-quality score and final KEEP/SELECTIVE/FULL decision must be made by GPT after reviewing **all 10** real original images plus metrics. FULL_STEAM_MIGRATION_CANDIDATE means a suggestion requiring subsequent whole-source machine-verified 12k equivalence/content diff and operator/release review, not immediate full replacement.
