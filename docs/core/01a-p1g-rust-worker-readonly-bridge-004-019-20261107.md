## Operation, exact surface and privacy
- `DEV_READY / PRODUCT_READ_ONLY_P1G_TO_RUST_WORKER_BRIDGE` only. This adapter is **a separate opt-in, unimported Worker-local module**, not connected to product/public message Router, 08 WEB Consumer or Community/Public Pages. - A Worker-local private `Uint8Array` copy of encrypted bytes (max128MiB) is decoded by **existing** P1G Codec to `jsonText`, and decoded `GameInfo.Version` must equal schema626. This does **not** prove external physical Steam FullVersion or Switch BID; Build is only an externally declared candidate and must be exact attested candidate in existing Rust owner. Never infer BuildID from schema or deviceType (Steam cross-save can be accessed from Switch).
- Conversion uses at most 349,524 UTF-16 code units per chunk / <=1MiB encoded UTF-8 (surrogate-pair-aware), <=128MiB total, delivered as async iterable to the **existing** one Rust ProductSession from `createProductWasmReadOwner.openDecoded()` in the SAME Worker. No whole decoded JSON transferred to UI or cloud; return only whitelisted bounded Rust Session receipt with all false flags plus `decodedByExistingP1gCodec:true`, `externalPhysicalBuildVerified:false`. A full decoded UTF-8 string remains in Worker transiently because existing codec uses `jsonText`; this is NOT zero-copy or 200MiB acceptance.
- Synchronous bridge-level epoch revoke ensures open A→B cannot resurrect A after delayed Codec decode, while existing Rust Worker owner enforces native SessionID, Revision, IndexGeneration, decoded JSON SHA, type/path allowlist, cursor, Close/Drop and Writer denial. On failure, Rust owner closes only the current epoch. Private ciphertext copy is zeroed even on failure; caller original bytes remain unchanged. No private decrypted content posted, persisted or emitted in test logs.
- `readCoreVersion`, `issueTypedCursor`, `readTypedPage` merely delegate to the same already accepted Worker owner/Rust bridge. Product `ReadDomain` remains OFF and the optional indexed-read feature is not auto-enabled outside Stage F synthetic test.
