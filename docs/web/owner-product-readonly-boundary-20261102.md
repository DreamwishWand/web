## Community session facts (source verified)

- `createCommunityBrowserClient()` builds a new `CommunityLabClient` reading its own `#session` from **tab-specific sessionStorage**. Its `session` getter returns a copy, not a subscription or server-verified Owner authority. Login saves `accessToken`, `refreshToken`, `expiresAt`, `userId`, email to sessionStorage.
- The existing `#validSession` and `#refresh` are private. They refresh an expiring session (under 60 seconds remaining) when a Community API is used. `#edge` may retry once after HTTP401, but this retry logic belongs to Community endpoints, **not** to the strict Owner Source153 adapter. Calling a new `CommunityLabClient` per page does not automatically synchronize token rotation or signout from another client instance. Cross-tab and external retirement/push revocation are not guaranteed.
- The new product module has only `ownerProductSignedSessionCandidate` (expiry greater than 60 seconds, canonical UUID-shaped Auth user, HTTPS configured service, publishable key). It passes an ephemeral bearer *candidate* **only in module closure**, never into HTML, logs, URL or the Source candidate state. It does **not** validate token signature, impersonate the signed user or grant Owner rights. Expired/near-expiry sessions are rejected until a separately verified refresh integration exists. A brand-new cloned session must not silently authorize a Work; server Source153 makes that decision.
- A future shared Community auth contract is required for an atomic asynchronous `getValidSignedSession({signal})`, single-flight rotation, 401 handling **without replay storms**, logout and Account/Session-change invalidation events across client instances, and cancellation/generation fences so that a token refreshed after logout cannot repopulate a prior Owner candidate. This is **Community Core/Auth + WEB** contract work; existing private methods were not rewritten here. The product adapter checks the current same-client signed session again before projecting results; this is a local safety check, **not** an external revocation guarantee.
