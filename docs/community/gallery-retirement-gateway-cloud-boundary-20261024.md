Existing `community-public-media` Edge **v5**, public JWT OFF as before, now routes eligible Gallery media to **an Edge-proxied GET binary stream**, with a per-request service-role RPC check and Storage Admin download. The POST resolver returns `media:{mediaId,transport:'edge_proxy',streamUrl,mimeType,byteSize,width,height,checksumSha256,rawStorageSignedUrlIssued:false}`, NOT a Storage signed URL. Stored bytes are never returned if a new request fails public/current/READY/CLEAR. As with all distributed media serving, an in-flight GET may have started before a retirement transaction and already-downloaded/browser-cached bytes cannot be recalled. **No positive retirement is enabled yet.** Existing non-Gallery DreamSnaps public POST still returns its original 300s signed URL; GET only accepts Gallery-managed media.

Existing JWT-authenticated `community-query` Edge **v14** adds `{query:'galleryRetirementPreflight',payload:{workId}}`, validates UUID and resolves session before service RPC. Non-owner yields a generic FORBIDDEN. No new standalone HTTP API and no public query of private owner details.
